Practical study and implementation of Data Science concepts based on
**Python Data Science Handbook** by **Jake VanderPlas**.

This repository is part of a structured learning path from Python and
Data Analysis to Data Science and Machine Learning.

## Learning Path

Python
→ NumPy
→ Pandas
→ Data Visualization
→ Exploratory Data Analysis
→ Feature Engineering
→ Machine Learning
→ Scikit-learn
→ Practical Data Science Projects

## Repository Structure

- `01-IPython-and-Jupyter` — Interactive Python and Jupyter
- `02-NumPy` — Numerical computing with NumPy
- `03-Pandas` — Data manipulation and analysis
- `04-Visualization-with-Matplotlib` — Data visualization
- `05-Exploratory-Data-Analysis` — Exploring and understanding datasets
- `06-Machine-Learning` — Machine Learning fundamentals
- `07-Feature-Engineering` — Preparing features for ML models
- `08-Scikit-Learn` — Practical Machine Learning with Scikit-learn
- `09-Regression` — Regression algorithms
- `10-Classification` — Classification algorithms
- `11-Clustering` — Unsupervised learning
- `12-Dimensionality-Reduction` — PCA and related techniques
- `13-Neural-Networks` — Introduction to neural networks
